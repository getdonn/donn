# @getdonn/spec

The donn persona schema: the zod schemas for persona files and layers, the harness-neutral resolved IR types, and validation. It also emits JSON Schemas for editors and other languages.

## Who uses it directly

Adapter authors, who build against its types. Otherwise it is internal to the donn CLI.
