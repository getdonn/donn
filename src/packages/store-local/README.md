# @getdonn/store-local

The local persona store. It mounts personas from a personas folder, the project's `.donn/` and `~/.donn/` onto one root, by layer.

## Who uses it directly

The control plane, which reuses the store's layout. Otherwise it is internal to the donn CLI.
