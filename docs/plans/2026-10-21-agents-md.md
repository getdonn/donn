# agents-md Adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `zzpersona write` renders the repo's project persona into a marked block in
`<repo>/AGENTS.md`, `--check` guards it in CI, and the report names what `AGENTS.md` cannot carry.

**Architecture:** A `gh stack` on `feature/agents-0-spec`, one layer per task
(`gh stack add feature/agents-<n>-<name>`). A pure adapter compiles the block; an optional `block`
on the SDK's overlay step says "merge between markers"; the executor's `applyOverlay` does the
merge; the CLI's `write` command selects the project persona and runs it.

**Tech Stack:** TypeScript, pnpm, turborepo, vitest, zod; Codex CLI for the opt-in e2e.

**Spec:** `docs/planning/11-agents-md.md`

## Global Constraints

- Markers, verbatim: `<!-- zzpersona:begin — generated from project/persona; edit the persona, not this block -->`
  and `<!-- zzpersona:end -->` (for a block named `zzpersona`; in general `<!-- <block>:begin …` / `<!-- <block>:end -->`).
- First block line, verbatim: `Generated by zzpersona from project/persona (<layers joined " → ">); edit the persona, not this block.`
- Headings: `## Knowledge sources` (as the Claude Code adapter), `## Tool rules` with `Never run:`, `Ask before:`, `Allowed:`.
- Error codes: `no-project-persona`, `user-layer-in-shared-file`, `agents-md-markers`, `not-a-file-harness`.
- Statuses: `created`, `updated`, `unchanged`, `removed`, `stale`.
- Size warning threshold: 24 KiB (24576 bytes) of block content.
- Persona for `write`: `project/persona`, overlay off, no switch/default.
- Every layer passes `pnpm turbo run build check-types lint test` and `pnpm format:check`; commits
  end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A file whose markers appear inside a fenced code block (documentation about zzpersona) is
   still treated as markers — expected: only lines that are exactly a marker count, and the doc
   example in a fence uses the same text, so refuse ambiguity → Task 3 test "counts only whole-line markers".
2. An `AGENTS.md` without a trailing newline gets the block appended with exactly one blank line
   between → Task 3 test "appends after a file without a trailing newline".
3. `--check` on a repo whose `AGENTS.md` is a symlink to a shared file writes nothing and reports
   honestly; `write` on it writes through to the target rather than replacing the link → Task 3
   test "writes through a symlinked AGENTS.md".
4. A persona with no instructions and no permissions still yields a valid block (header only) →
   Task 2 test "renders a header-only block".
5. `write` run from a subdirectory of the repo targets the repo root's `AGENTS.md` → Task 4 test
   "writes the repo root's AGENTS.md from a subdirectory".

### Task 3: `applyOverlay` (`feature/agents-3-executor`)

**Files:** Create `src/packages/executor/src/overlay.ts`, `overlay.test.ts`; export from `index.ts`.

**Interfaces:**
```ts
type OverlayMode = "write" | "check" | "remove";
type OverlayStatus = "created" | "updated" | "unchanged" | "removed" | "stale";
function applyOverlay(step: Extract<Step, { kind: "overlay" }>, root: string, options: { mode: OverlayMode }): Promise<{ path: string; status: OverlayStatus }>;
class OverlayMarkersError extends ExecutorError { line: number } // code agents-md-markers at the CLI
```
Rules (spec §2): a marker counts only when the whole line (trimmed) starts with
`<!-- <block>:begin` or equals `<!-- <block>:end -->`; missing file → create (write) / stale
(check) / unchanged (remove); no markers → append after one blank line; one block → replace; any
other marker shape → `OverlayMarkersError` naming the 1-based line, nothing written. Line endings
follow the file (CRLF if its first line ends with `\r\n`). `check` returns `unchanged` when the
merge result equals the file, else `stale`. `remove` deletes the block (and the blank line before
it that `write` added); deletes the file if only whitespace remains. Without `block`, the whole
file is `content`. A `path` that is not `isContainedPath` → `ExecutorError`. Writes via temp file
and rename on the symlink's target (`realpath`), so a symlinked `AGENTS.md` stays a symlink.

- [ ] **Step 1: Failing tests**: every row of spec §2's table; `it("preserves text outside the block byte for byte")`; CRLF; `it("counts only whole-line markers")`; `it("appends after a file without a trailing newline")`; `it("writes through a symlinked AGENTS.md")`; malformed shapes (begin only, end only, two blocks) throw with the line and leave the file unchanged; `check` → `stale`/`unchanged` writing nothing; `remove` with and without other content; `../x` refused.
- [ ] **Step 2: Run** `pnpm --filter @zzpersona/executor exec vitest run src/overlay.test.ts` — Expected: FAIL.
