`donn agent create|list|sync`: create an agent from an eve or path template on a persona (declaring it in the project persona when needed), list the project's agents with their state, whether the persona changed since the last sync, and `recreate needed` when its template, target, path or world did, and `sync` to recompile the persona into donn's files without touching `agent.ts`.

`donn agent env <name> [--resolve] [--format dotenv|json]` lists the environment an agent needs: persona and gateway secrets (names and refs, values only with `--resolve`), plain values, and what is set at run time (the route token, the Workflow database). `donn agent exec <name> -- <command>` runs a command in the agent's folder with that environment resolved, and a secret that does not resolve stops it naming the variable and the ref. `eveEnv` now applies its extra variables before forcing production, so a persona env cannot bring back `NODE_ENV=test`, `VITEST`, `EVE_DEV` or `EVE_MOCK_AUTHORED_MODELS`.

`donn agent run <name>` builds a created agent (`eve build`) and starts it (`eve start --host 127.0.0.1 --port 0`, `NODE_ENV=production`, its env resolved, a new route token per run) through the daemon when one runs, else in the foreground until Ctrl-C; `--dev` runs `eve dev` with its terminal UI instead, never through the daemon. A `vercel` agent is refused (`target-not-runnable`: its routes fail closed under `eve start`); `--dev` still runs it. `donn agent stop <name>` stops the agent's whole process group (SIGKILL after 10 s), waits for the server to exit even when `pnpm exec` went first, and reports any `eve-sbx-*` sandbox containers still running; `donn agent logs <name> [--follow]` prints (or tails) the daemon run's log at `~/.donn/agents/<project hash>/<name>.log`, which never holds the token or a secret value. The daemon serves `GET /agents` (with each run's route token) and `POST /agents/run|stop`, emits `agent.created`, `agent.started`, `agent.stopped` and `agent.failed` (never a token or env value), stops its agents when it closes, and runs `agent list|sync|run|stop|create|build|env` (not `env --resolve`) from `POST /run`. `donn agent list` shows `running` with the URL, and `donn status` adds a line per created agent: `agent  <name>  <target>  <state>  current|stale`.
